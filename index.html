What this is

A working notebook of engineering notes and small utilities. Everything here is written from the metal up: memory layouts, syscall boundaries, protocol framing, and the failure modes that show up at 3 a.m. Most of it is Windows and Linux userspace, with occasional forays into kernel interfaces and network captures.

Focus areas

  • Systems tooling — process inspection, handle and memory work, tracing, log correlation.
  • Network analysis — packet capture pipelines, protocol dissection, latency measurement.
  • Build and release — reproducible builds, CI wiring, cross-compilation for Win32 and POSIX.
  • Reverse engineering — static analysis, binary diffing, and documenting undocumented interfaces.

Notes

Reference material lives in short, self-contained write-ups rather than long guides. The goal is a page you can read in one sitting and then act on: exact constants, exact flags, exact failure conditions. No filler.
